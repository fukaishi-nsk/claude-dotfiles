# AI系アプリ・CLIの毎朝の更新（自動）

深石さんの指示（2026-11-12）:「インストールされてるAI系のアプリを一括で最新状態に」「更新頻度が多いから、毎日の習慣にしてほしい」「火〜土の7:30で登録して」。

火〜土の朝にしている理由（2026-11-12 に直近60日を集計）: 更新は米国の平日の日中＝日本時間の火〜土の未明〜午前に出る（Claude Code は60日で48回・1〜6時に集中、Gemini CLI はほぼ毎週水曜の5〜6時台）。8:30 からの他の定期実行より前に終わらせる。

この手順で行うことは**事前承認済み**（範囲はここに書いたものだけ）: 下のスクリプトの実行（CLIの更新・更新待ちアプリの終了と起動）と、Slack `#log_fukaishi` への報告。

## 1. 実行する

次の1コマンドだけを実行する（数分かかることがある）。

```bash
bash ~/claude-dotfiles/scripts/ai_update.sh
```

スクリプトがすること（中身を変えたい時はスクリプトの正本 `~/claude-dotfiles/scripts/ai_update.sh` を直す）:
- CLI を最新にする: Claude Code・Gemini CLI（npm）、Codex CLI（brew cask）、agy、Grok CLI
- ChatGPT・Grok Bot・Nani・Antigravity・HyperFrames のうち、**起動中で更新待ちのプロセスがいるものだけ**を終了→更新の適用を待つ→起動し直す
- 出力は1行1件。先頭の語が種別（更新 / 変化なし / 再起動 / 更新待ち / 注意 / 失敗）

## 2. やらないこと

- **agent-browser は更新しない**（0.34.0 固定運用）
- **Claude デスクトップは再起動しない**（この定期実行がその中で動いている）。「更新待ち」と出たら報告に書くだけ
- **`claude remote-control` は再起動しない**（遠隔接続が切れる）。「旧版のまま」と出たら報告に書くだけ
- スクリプトに無いアプリ・ツールを自分の判断で更新しない。パスワードや認証を求められたら入力せず、失敗として報告する
- 失敗した更新を別の方法でやり直さない（原因と出力を報告する）

## 3. 報告

- 出力に「更新:」「再起動:」「失敗:」の行が**1つも無い日は、何も投稿せずに終わる**（「注意:」「更新待ち:」だけの日も投稿しない）
- 1つでもあれば、Slack `#log_fukaishi`（channel_id `C03119VSJGK`）に日本語で投稿する。冒頭に `<@U02PBGQ62BB>`
- 書くこと: 更新されたもの（前の版 → 後の版）、再起動したアプリ、失敗（スクリプトの出力をそのまま）、その日に出ていた「注意:」「更新待ち:」の行
- スクリプトの出力に無いことは書かない。版番号は出力の数字をそのまま使う
- Slack に投稿できなかった時は、この実行の最後のメッセージにその旨と報告の中身を書く
