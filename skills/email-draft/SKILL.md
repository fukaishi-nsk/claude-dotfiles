## 進め方（必須）

1. **返信の場合は必ず元スレッドを読む**（Gmail検索→get_thread）。相手の宛名表記・過去のトーン・約束事項を確認する
2. **まずテキストで文面を提示し、承認を得てからGmail下書きを作成する**。下書き作成も外部書き込み＝勝手にやらない
3. 対応報告を含む場合、**実作業が完了してから送る**順序になっているか確認する（完了形で書くため）
4. **リンク汚染に注意（2026-07-13 姫路エコテックで実発生）**: APIで作った下書き（素のURL）をGmail Webの編集画面で開くと、Gmailが裸のURLを自動リンク化→`https://www.google.com/url?q=...&source=gmail&ust=...`のリダイレクトURLに書き換え、**本文テキストごと焼き込んで送信される**ことがある。対策:
   - 下書き作成を報告する際、「送信前に署名のURL（https://nanco.io）が素のままかご確認ください」と毎回一言添える
   - 送信後の確認は**FULL_CONTENTで本文末尾（署名・リンク）まで**見る。snippetでは署名まで届かない
   - 送信済みメールに`google.com/url?q=`を見つけたら即報告する
   - **htmlBodyで`<a href>`タグ化の検証結果（2026-07-13 姫路エコテック 16:04送信で実測）**: 部分的に有効。**表示テキストは素のURLのまま守られた**（前回のような本文焼き込みは発生せず）。ただしhref属性はGmailが`google.com/url?q=...`リダイレクトに書き換えて送信する（リンク自体はリダイレクト経由で機能する）。結論: 下書きは必ずhtmlBodyで`<a href>`タグ化して作る。見た目の汚染は防げるので実用上OK
   - **hrefまで素に戻す確実な手順（2026-07-22 姫路エコテック送信で実測・確定）**: 編集画面で署名URLをクリック→リンクポップアップの**「削除」でリンク解除**→送信。送信後メールをFULL_CONTENTで実体確認したところ**hrefも素の`https://nanco.io`のままクリーンだった**。下書き作成を報告する際は「開いたらリンクをクリック→『削除』でリンク解除してから送信」を毎回案内する（2026-07-30 GREENING送信でも再実証・hrefは素の`https://nanco.io`のままクリーン）
   - **根本抑止は不可**: 書き換えはGmail Web編集画面を開いた時点で起きるGmail本体の仕様。コネクタ・下書きの作り方では防げない
   - **恒久対応の候補（未検証）**: Gmail設定→署名で送信エイリアスsupport@nanco.io用の署名を登録し、AI下書きには署名（区切り線・URL含む）を入れない運用。署名はGmail自身が挿入するためAPI下書き由来の書き換え対象外になるはず。検証したら結果をここに追記
5. **返信下書きの修正にupdate_draftを使わない（2026-08-06 島津で実発生）**: update_draftは返信ヘッダを壊し、**下書きがスレッドから外れて単独メール化する**（threadIdが変わる）。さらにエラーを返して下書き自体が消えたケースもあり。修正したい時はcreate_draft（replyToMessageId付き）で作り直す。作成後は**list_drafts（FULL）でthreadId・宛先を実体確認**する（同一スレッドに複数の返信下書きは共存できる）
   - htmlBodyには実タグ（`<br>`や`<a href>`）をそのまま書く。`&lt;br&gt;`とエンティティ化すると本文にタグ文字列が見えてしまう（2026-08-06 実発生→作り直しで対処）

## 文体ルール（nancoサポート）

- 宛名: 「会社名（改行）姓＋**さま**」。「様」ではなくひらがな（例: 岳本さま、小岸さま）
- 名乗り: 「在庫管理アプリnancoサポート 深石です。」または「在庫管理アプリnancoサポートです。」。相手が「深石様」宛で書いてくる進行中案件では**名前入り**にする
- **1文1行・短文**。前置き最小で要件から入る
- **空行は話題ブロックの切れ目だけ**に入れる。文ごとに空行を入れない（AIは入れがち→深石さんが毎回削る。2026-07-13 姫路エコテック返信で実測）
  - 1ブロックになるもの: 宛名2行／名乗り＋お礼／本題（日程確定＋当日の案内リンクなど関連する文の連なり）／締め＋署名（**締めと署名の間に空行なし**）
  - 実例（送信形）:
    ```
    姫路エコテック株式会社
    藤井さま

    在庫管理アプリnancoサポート 深石です。
    ご返信ありがとうございます！

    それでは、7月22日（水）14:00〜15:00でお願いします。
    当日は、以下のリンクからご参加ください。
    https://meet.google.com/xxx-xxxx-xxx

    ひきつづき、よろしくお願いします。
    +-+-+-+-+-（署名）
    ```
- お礼は「ご連絡ありがとうございます！」など「！」を適度に使う明るいトーン（義務ではない。内容に合えばで良い）
- 依頼は「〜いただければと思います」「〜いただけますでしょうか」。「〜いただけますと幸いです」は硬め＝多用しない
- 対応報告は**完了形**「〜いたしました」（先に作業してから事後報告が型。例:「トライアル期間を3月末まで延長いたしました」）
- 期限・期日は「◯月末まで」と月末区切り
- 次の一手を一言添える（「ぜひ、触ってご検討ください」「お気軽にご相談ください」「お時間ください」）
- 締めは「**ひきつづき、よろしくお願いします。**」または「ひきつづき、nancoをよろしくお願いします。」
- 署名:
  ```
  +-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-+-
  はじめやすい、続けやすい在庫管理アプリ「nanco」
  https://nanco.io
  ```

## 共感の型（2026-07-13 プラユスフィール返信・3往復の添削で確定）

構成は最大2行: **①一般化＋②経験根拠＋③誘い水**

> 始めるタイミングや社内の足並みを揃えるところは、どのお客さまも一番苦労されるところです。
> 私たちもいろんな会社さんの立ち上げをご一緒してきましたので、導入前のお困り事なども含めて、気楽にご相談ください。

- **気持ちの表明はしない**（「味方でありたいと思っています」等）＝親切の見せつけになる
- **慰めより苦労の承認**（「気にしないで」より「皆さん苦労されるところです」）
- **相手の困り事を具体的に言い当てない**（「現場への広め方なども」→「導入前のお困り事なども」と修正された実績。何に困るかは相手に委ねる。顧客の社内事情に踏み込まない）

## オンライン相談への誘導の型（2026-07-17 オーガイホールディングス返信の添削で確定）

フォーム問い合わせ等で「ソリューションを探している」相手を無料オンライン相談へ誘導する時。
操作の個別質問に見えても、導入検討中の相手なら操作回答より相談誘導に舵を切る（深石さん判断: 「操作に困っているのではなくソリューションを探している」）。

送信実例（オーガイHD 2026/7/17）:
```
オーガイホールディングス株式会社
増岡さま

在庫管理アプリnancoサポート 深石です。
お問い合わせありがとうございます！

nancoでは、無料のオンライン相談をご用意しています。
現在のお困りごとや解決したいことを伺い、最適な運用方法をご提案、サポートいたします。
私たちもいろんな会社さんの導入をご一緒してきましたので、他社さんのうまくいっている使い方などもご紹介できます。
以下のリンクから、ご都合の良い日時をご予約いただければと思います。
https://www.nanco.io/free-consultation

ご検討よろしくお願いします。
ひきつづき、よろしくお願いします。
+-+-+-+-+-（署名）
```

添削で確定したポイント（AIドラフト→深石さん送信版の差分）:
- **前置きブロックは削除**（「導入をご検討いただき、うれしいです」「ぜひ御社のペースでお試しください」等）。お礼の次はすぐ本題
- 相談案内は**こちらが何をするかを動詞で示す**:「現在のお困りごとや解決したいことを伺い、最適な運用方法をご提案、サポートいたします」。「『〜したい』といったご相談を歓迎しています」のようなセリフ例示＋受け身の「歓迎」は使わない
- **聞かれていない先回り案内は書かない**（トライアル延長の案内は削除された）。1通のCTAは1つ（相談予約リンクのみ）
- 締めは「ご検討よろしくお願いします。」を挟んでから「ひきつづき、よろしくお願いします。」の**2行締め**もあり
- 予約URLは https://www.nanco.io/free-consultation（実在検証済み。help.nanco.io/free-consultation は404）

## リマインド・催促の型（2026-07-13 姫路エコテック日程確認で確定）

相手の返信が止まっている時。責めない・経緯を蒸し返さない。

1. 「◯◯の件、ご連絡です。」で要件から入る（「ご確認です」より自然）
2. 相手が返しやすいよう**条件を再掲**する（例: 「姉崎からご案内のとおり、7月22日（水）は13:00〜17:00の間でしたらいつでも大丈夫です！」）
3. 相手に求めるアクションは**1つだけ**（例: 「ご都合の良い開始時間をご返信いただければと思います」）
4. 確定後のこちらの動きを予告して締める（例: 「お時間が確定しましたら、あらためてミーティングのご案内をお送りします」）

## 日程変更を承諾する型（2026-07-30 GREENINGでほぼ無修正送信）

顧客から日程・時刻の変更依頼が来た時。承諾は2行で完結する。

送信実例（GREENING 2026/7/30。AI下書きからの修正は1箇所のみ）:
```
(株)GREENING
志村さま

在庫管理アプリnancoサポートの深石です。
ご連絡ありがとうございます！

8月19日（水）の訪問・打ち合わせは、15:00開始で承知いたしました。
当日は、プリンター実機とラベルをお持ちして伺います。

ひきつづき、よろしくお願いします。
+-+-+-+-+-（署名）
```

- 構成: 承諾1行＋当日にやることの再確認1行で完結。相手の近況報告（「社内でも検証を進めます」等）には触れない
- 添削された1箇所: 「8月19日（水）の**お打ち合わせ、**15:00開始で〜」→「8月19日（水）の**訪問・打ち合わせは、**15:00開始で〜」
  - **予定の呼び名は実態に合わせる**: こちらが訪問する予定なら、相手が「お打ち合わせ」と書いてきても「訪問・打ち合わせ」と言い直す

## ワークスペース招待・事前準備の案内の型（2026-07-30 GSIクレオスでほぼ無修正送信）

顧客をnancoワークスペースへ招待した後の案内メール。テスト・訪問日が近い時の事前準備連絡を兼ねる。

送信実例（GSIクレオス森さま宛 2026/7/30。AI下書きからの修正は2箇所）:
```
株式会社ＧＳＩクレオス
森さま

Nスケッチ 深石です。
先日はお時間をいただき、ありがとうございました！

8/3（月）の棚卸しテストに向けて、nancoのワークスペース「GSI_棚卸しテスト_2607」へご招待をお送りいたしました。
「Nanco サポート（support@nanco.io）」から届く招待メールより、ご登録をお願いします。
もし届いていないようでしたら、お知らせください。

6月末時点の在庫データ2,821件を取り込み済みで、品番が先頭に出る表示や、棚ごとのフォルダ分けも設定しています。
ログイン後は、ラベルの印刷もお試しいただけます。
更新された在庫データをいただければ、すぐに反映いたします。

操作方法など、わからないことがあればお気軽にお問い合わせください。
当日は9時に桜井物流センターへ伺います。

ひきつづき、よろしくお願いします。
+-+-+-+-（署名）
```

- 構成: ①招待報告（完了形）＋登録依頼＋届かない場合の逃げ道 ②準備済みの中身（データ件数・設定）＋ログイン後にできること＋データ更新の受け入れ ③質問歓迎＋当日の予定＋締め
- 招待メールの差出人（Nanco サポート／support@nanco.io）を明記して探しやすくする。「もし届いていないようでしたら、お知らせください」の逃げ道を添える
- 添削された2箇所:
  - 「お気軽にお**聞き**ください」→「お気軽にお**問い合わせ**ください」（質問歓迎は「お問い合わせ」表現）
  - 締め「ひきつづき、よろしくお願いします。」の**前に空行**が追加された（締め文を独立ブロックにする形もある）
- **スレッド選択の学び**: AIは直近のNDA事務スレッドへの返信下書きを作ったが、深石さんは**案件のメインスレッド（在庫管理サービス相談）に返信**して送った。返信先は「最も文脈が続いている本題スレッド」を選ぶ。迷ったらどのスレッドか確認する
- **CCは実態に合わせて追加**: 下書きのCC（姉崎さん）に加え、送信時に現場担当の片山さんとsupport@nanco.ioが追加された。進行中案件は関係者＋サポート窓口をCCに含める前提で提案する
  - 読点で流す「〜のお打ち合わせ、15:00開始で」より「〜は、15:00開始で」と助詞で受ける
- 付随作業もセット: 承諾メールと同時に自分のカレンダー（本体予定＋移動ブロック）も新時刻へ変更する（GREENINGでは訪問11:00-14:00→15:00-18:00、移動10:00-11:00→14:00-15:00を承認のうえ同時実施）
